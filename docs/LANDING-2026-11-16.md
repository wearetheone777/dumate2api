## 5. 本轮新增的坑（都在 CLAUDE.md 里有详细段落）

1. **运行态配置字段要改三处**：`defaults()` / `FIELDS` / `Load()` 返回体——漏第三处表现是「存进去了但读出来是 undefined」。
2. **同一事实写两份必漂移**：桶字段清单有三份（造桶/合并/读盘）、会话键算法曾有两处（`sessionKeyOf` 与 qoder 内部）。
3. **读 livecfg 的模块在测试里必须钉 `DUMATE_ADMIN_DATA`**，否则本机面板配置会让断言变机器相关。
4. **`const X = {…};` 不能按 `\n};` 正则收尾**——单行对象会被吃穿，改代码用完整单行串当锚点。
5. **阈值类测试别只调数字**：早停用例失败的真因是换号 patience 叠加，调阈值只是把失败藏起来。
6. **前端两块（自动刷新/阅读模式）没有自动化测试**——仓库没有前端测试基座，只能构建+人工核对。
7. **图片「缩完更大」是真实存在的**：稀疏内容（白底少字）缩完反而涨 4%，所以 `shrink` 保留「不更小就放弃」。

## 6. 能否同步到 `stable/`（**评估，不执行**）

### 6.1 现状

- `stable/` **一行未动**（`git status -- short stable/` 为空），9080 的对外服务不受本轮任何影响。
- 快照现有 53 个顶层 `.js`；`stable/SNAPSHOT_FROM.txt` 记的是「102 个 .js」（含子目录），指纹 `33cab228…`。

### 6.2 闭包口径比文档写的更复杂（本轮实测）

按 `require` 文本从 `src/server.js` 递归，得到 **121 个文件**：
顶层 67 + `qwenwork/` 15 + `traework/` 18 + `qoder/` 10 + `workbuddy/` 7 + `admin/` 4。

两个必须注意的点：

1. **递归会多带**：`admin/{auth,router,store,routes/accounts}.js` 出现在闭包里，但它们是
   **懒加载**（管理端/审计路径才 require），快照历来不含管理端。所以「静态闭包」是**上界**，
   不是发布清单——发布清单必须靠**实测**（独立端口启动 + 三条通道 ready）来定。
2. **口径不一致**：文档记 73（顶层 43 + 子目录 30），实际快照 102，我算出的上界 121。
   三个数都「对」，因为分别指「顶层文件数」「快照内全部 .js」「静态闭包上界」——
   **发布时不要照抄任何一个是非，重算并以实测为准**。

### 6.3 建议的发布步骤（若决定发布）

1. 从 `src/server.js` 出发算闭包，**剔除** `admin/**`（管理端不进快照），得到候选清单；
2. 逐文件复制到 `stable/src/` 同路径，**另加** `src/dumate-catalog.default.json`（读盘资产，不在 require 闭包里）；
3. 逐字节比对 `stable/src` 与 `src` 的同名文件；
4. **独立启动实测**：`DUMATE2API_PORT=19099 DUMATE_ADMIN_DATA=<tmp> node stable/src/server.js`，
   确认 dumate / qwenwork / traework / qoder 都 ready（本轮新增的 8 个文件若漏拷，
   会在启动或首个请求时直接抛 `MODULE_NOT_FOUND`——这是最容易发现的一种失败）；
5. 抽查新增能力：`/v1/models` 含路由组、413 图片上限、`session_key` 落日志；
6. 更新 `SNAPSHOT_FROM.txt`：指纹（算法：按相对路径排序后 `[路径+LF+内容]` 拼接的 sha256）+
   来源提交 + 覆盖说明 + 验证记录。

### 6.4 风险判断

| 风险 | 说明 |
|---|---|
| 中 | 本轮动了 `server.js` 的请求主路径（图片预算、路由组、会话键、闸门埋点），快照同步后**影响面是全部协议入口** |
| 中 | `livecfg` 新增 `throttle`/`imageBudget` 字段，若快照与主目录**共用 `data/`**（现状如此），旧快照读到新字段会按未知键丢弃——不会炸，但两个版本对新配置的理解不同 |
| 低 | 端口/数据目录/协议形状均未变 |
| 建议 | 先按 §3 跑全量离线验证；发布后在 9080 上抽查「一次普通对话 + 一次 413 + 一个路由组」三件事 |
